# Como usar a Arvak Library

## Quero saber o que está parado

- Na barra lateral, clique em **Pausados** para ver os projetos que você marcou manualmente como pausados.
- Clique em **Sem atualização** para ver os repositórios cujo último push público aconteceu há mais de 30 dias. É apenas um sinal de inatividade no GitHub, não uma classificação do projeto.
- Para classificar: clique em **⋯** no cartão, escolha uma **situação** e toque em **Salvar alterações**.

## Quero voltar a programar alguma coisa

Abra **⋯** e preencha **Próximo passo** com uma ação pequena e concreta. Exemplo: `testar exportação do Contraponto no celular`. O cartão passará a mostrar essa anotação.

## Quero abrir um aplicativo

Clique em **Abrir app**. Se o site não tiver sido cadastrado, o cartão mostrará **Ver código**, que abre o repositório no GitHub. Para cadastrar a página: **⋯ → Link para abrir → Salvar**.

## Quero encontrar meu projeto favorito

Toque na estrela ★ do cartão e depois no menu lateral **Favoritos**. Ao abrir um projeto, ele aparece também em **Acessados recentemente**.

## Quero levar minhas notas para outro computador

Na biblioteca original: **Dados e backup → Exportar**. Mande o JSON para o outro computador. Na biblioteca de destino: **Dados e backup → Importar**. O backup substitui as personalizações existentes naquele navegador.

## Quero publicar sem usar terminal

Leia as instruções completas no [README.md](README.md). Resumo: novo repositório `arvak-library` → upload de `index.html` → Settings → Pages → Deploy from a branch, `main` `(root)`.
